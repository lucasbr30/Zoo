 Este é um projeto em Python que simula a organização de dados de um zoológico, utilizando arquivos JSON para armazenar informações sobre animais e cuidados.

## Estrutura do Projeto

- `dados/animais.json`: contém as informações dos animais.
- `dados/cuidado.json`: contém os dados de cuidados dos animais.
- `aplicativo.py`: script principal que manipula os dados.
